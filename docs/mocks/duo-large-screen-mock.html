iPhone Duo 内側・外側 モック

内側 951×669pt（横向き・開いた状態）／外側 466×678pt（閉じた状態）。数値はダミー

表示内容は現在のiOSアプリ（銘柄面の各カード、リスト、比較）に合わせています。新規 は大画面で足す提案です。

ホーム（検索 + feed/update）

  • 左に常設の検索バー。未入力は「最近あなたが調べた企業」、入力中は「検索候補」。右に 新規 feed/update「最近有報が更新された企業」を常時表示（現行は6社ずつのページ送り → 大画面では縦に並べてスクロール）。行をタップすると右ペインが銘柄画面に切り替わり、‹ でfeedへ戻る。

銘柄画面（内側）

  • 銘柄ピルはやめ、アイコン・社名・コード/業種の見出しと Overview（最大5行）を常時表示。右上に星（共有ボタンなし）と 新規 表示切替（アイコン: 全画面 / 2つ）。
  • リスト＋詳細（初期）: 左に「あなたの追加した企業」、右に分析カードを2列で同時表示。
  • 全画面: 収益構造のウォーターフォールを大きく表示し、右に要因の式と意味を常時表示。‹ でリストへ戻る。
  • 2つ: 左右に別銘柄の銘柄画面。ペインをタップでフォーカス移動。閉じたとき（外側）はフォーカス側が残る。検索アイコンで名前・コードから入れ替え。

比較

  • 現在の「比較したい業種を選択 → 銀行ランキング」の7指標をそのまま使用。新規 ピン留めして右で並列比較。新規 各行に推移のミニグラフ、右に選択した指標の過去の推移（5年）を重ね描き。

開閉（ボタンで試せます）

  • 開く: 外側の画面に対応する内側の画面へ。ホーム→ホーム、リスト→リスト、比較→比較。銘柄画面は、ホームから開いていたらホームの右ペイン、リストから開いていたらリストの右ペインで同じ銘柄を開く。
  • 閉じる: 内側の画面に対応する外側へ。2つ表示のときはフォーカス側の銘柄の銘柄画面。

外側

  • 現行iOSと同じ中身＋Duo版のタブ: タブは右の縦レール（ホーム/リスト/比較）、ホームはfeed（6社ずつページ送り）、リストは3列タイル、銘柄画面は ‹・社名ピル（タップでOverview）・チャート・ブックマーク。

クリックできます: リストの行、右上の表示切替アイコン、ウォーターフォールの棒、2つ表示の検索、比較の指標とピン。
